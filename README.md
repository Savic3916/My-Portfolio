## 🚀 Getting Started

You need [Node.js](https://nodejs.org) and [Git](https://git-scm.com) installed.

```bash
git clone https://github.com/Savic3916/My-Portfolio.git
cd My-Portfolio
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000). The page reloads when you edit files.

To create a production build, run:

```bash
npm run build
```
